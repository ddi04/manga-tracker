安装到 iPhone

像 App 一样打开

  1. 使用 iPhone Chrome 打开本页面。
  2. 点击地址栏右侧的“分享”。
  3. 选择“添加到主屏幕”，然后确认添加。

一次设置

自动复制漫画链接

创建一个只在分享菜单中运行的快捷指令。它不会上传链接，也不会打开另一份漫画记录。

  1. 新建快捷指令命名为“复制漫画链接”。
  2. 开启共享表单在详细信息中开启“在共享表单中显示”，接收类型只选择“URL”。
  3. 复制快捷指令输入添加“复制到剪贴板”操作，复制内容选择“快捷指令输入”。
  4. 添加完成通知添加“显示通知”，内容填写“链接已复制，请返回漫画记录”。
以后这样使用

漫画页面 → 分享 → 复制漫画链接 → 切回主屏幕上的“漫画记录”。
