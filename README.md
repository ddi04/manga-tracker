# 漫画记录

一个面向 iPhone 的中文漫画阅读进度 PWA。所有漫画名称、网址、进度、标签和笔记仅保存在当前设备的浏览器本地存储中，不包含账号、云同步、统计脚本或远程数据库。

## 功能

- 手动添加漫画名称和网站地址
- 点击“开始阅读”打开漫画网站
- 看完后复制当前章节链接，返回工具即可预览并更新下次继续阅读的网址
- 使用“+1 话”快速推进进度，或直接填写任意新进度
- 支持自定义标签、笔记、搜索、标签筛选和排序
- JSON 备份导出与合并导入
- 安装到 iPhone 主屏幕后可离线打开记录列表

## 本地运行

服务工作线程需要通过 HTTP 访问，不能直接双击 `index.html` 测试完整离线功能。

```powershell
node server.mjs
```

然后打开 `http://localhost:4173`。

## 部署到 GitHub Pages

1. 将这些文件提交到 GitHub 仓库的 `main` 分支。
2. `.github/workflows/deploy-pages.yml` 会自动运行并发布 GitHub Pages。
3. 使用 iPhone Chrome 打开生成的网址，点击“分享 → 添加到主屏幕”。

## 数据说明

记录保存在浏览器的 `localStorage` 中，不会随 GitHub 代码提交或上传。清除 Chrome 网站数据、删除主屏幕 Web App 或系统回收网站存储都可能导致记录丢失，请定期使用“设置 → 导出备份”。
